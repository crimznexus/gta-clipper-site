GTA Clipper

An internal clipping tool for the Crimson Painsmith YouTube channel.

What it does

GTA Clipper runs on the channel owner's computer during our own GTA IV live streams on Crimson Painsmith. It records the stream, finds the moments where live chat reacts most, cuts them into short vertical clips, and uploads them as YouTube Shorts to our own channel.

How it uses YouTube

  • It uses the YouTube Data API v3 videos.insert endpoint with the youtube.upload OAuth scope.
  • The only account that signs in is the owner of our channel. The tool is not offered to anyone else.
  • Every upload starts as private, and the owner reviews it in YouTube Studio before publishing.
  • It reads no data from other users' accounts or channels.

The tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service.
