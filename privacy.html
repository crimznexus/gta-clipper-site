GTA Clipper: Privacy Policy

Last updated: November 18, 2026

GTA Clipper ("the tool") is an internal tool run by Muhammad Faizan Mustafa for the Crimson Painsmith YouTube channel. This policy explains what data the tool uses and how.

YouTube API Services

The tool uses YouTube API Services. By using the tool you agree to be bound by the YouTube Terms of Service. Google's privacy practices are described in the Google Privacy Policy.

What data the tool accesses

  • Google account authorization. The channel owner signs in with Google OAuth and grants the youtube.upload scope. The tool receives an access token and a refresh token, which allow it to upload videos to that channel. It does not receive the account password.
  • Our own stream. The tool records our own public live stream and its public live chat to find highlight moments. Chat messages are used only to measure how much chat is reacting. They are stored on the owner's computer while clips are made and are not shared or sold.

The tool does not read, collect or analyse any other user's private data, YouTube account data, analytics or statistics.

How the data is used and stored

  • The OAuth tokens are stored only on the owner's computer and are used only to upload clips to our own channel.
  • Video clips and chat logs are stored on the owner's computer. They are not sent to any third party.
  • No data is sold, shared, used for advertising, or combined with other data.

Revoking access and deleting data

Access can be revoked at any time on the Google security settings page: https://myaccount.google.com/permissions. Deleting the tool's token file on the owner's computer also removes the stored authorization. Clips and chat logs can be deleted from the tool's folder at any time. For any data request, contact us at icrimsoncodes@gmail.com and we will respond within 30 days.

Changes

If this policy changes, the new version will be posted on this page with a new date.
